# Collega Workspaces Directory
Deze map is gereserveerd voor persoonlijke mappen van docenten en bijdragers.

Elke docent kan hier een eigen submap aanmaken (bijvoorbeeld `collega-workspaces/david/`, `collega-workspaces/gert/`, etc.) om eigen laboefeningen, examens, scripts of experimentele topologieën in te bewaren zonder het centrale project te beïnvloeden.
